# Panduan Kontribusi Latihan

Repo ini berisi panduan kontribusi untuk proyek latihan open source. 
Siapapun bisa berkontribusi ke proyek ini.

## Cara Berkontribusi

1. Fork repo ini
2. Buat branch baru
3. Lakukan perubahan
4. Ajukan Pull Request

## Kontak

Jika ada pertanyaan, silakan buka Issue baru.
